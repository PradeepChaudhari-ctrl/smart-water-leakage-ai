# Dataset Strategy

## Primary Benchmark
LeakDB

## Purpose
Water distribution network leakage detection and localization.

## Important Note
LeakDB is a research benchmark containing realistically simulated
water-distribution leakage scenarios. It is not direct real-world
sensor data.

## Planned Features
- Pressure
- Demand
- Flow
- Time
- Leakage status
- Leakage location/type (where available)

## Planned ML Tasks
1. Leakage Detection
2. Leakage Localization
3. Leakage Severity Analysis
4. Anomaly Detection

## Future Real-World Extension
Real flow/pressure sensor data will be integrated later through ESP32.
